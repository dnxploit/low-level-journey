# low-level-journey

Hi, I'm Dani, networking student from Valencia (CCNA certified) on a
two-year path into low-level security: reverse engineering, exploit
development and Windows kernel internals.

This repo is my public log. Every phase ends with code, notes or a
write-up here, so you can see exactly how I got from C basics to writing
my own Windows driver.
